# Changelog

## 0.1.0

- First release: Terraform state (`.tfstate`, `.tfstate.backup`) and JSON plan (`.tfplan.json`) files in a read-only viewer, parsed locally with plain JavaScript.
- Supports Terraform state format v4, legacy state v3 and `terraform show -json` plan output.
- Resource inventory table (provider, type, name, mode, module, dependencies), Outputs tab, Dependencies tab, sensitive-value masking toggle, local search and filter, and state health findings.
- Zovo Pro tools with 1 free try each: two-file state or plan Markdown drift report, offline sensitive-attribute and public-exposure Markdown audit report, and non-destructive CSV, JSON and Mermaid dependency graph export. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
